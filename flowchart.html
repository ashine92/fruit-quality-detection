Luồng 1 – Video Stream
📷 Camera USB
→ CameraReader Thread (liên tục)
→ StreamWorker (resize + encode)
→ WebSocket ↑ video_frame_upstream
→ Backend broadcast
→ React Dashboard live view
Luồng 2 – AI Inference
📸 Frame mỗi 2 giây
→ InferenceWorker encode JPEG
→ Azure Custom Vision POST :8080
→ Parse predictions → filter ≥70%
→ POST /api/v1/inferences + ảnh
→ SQLite DB lưu kết quả

🖱️ User bấm nút trên Dashboard
→ Emit set_classification_state
→ Backend cập nhật global state
→ Broadcast classification_state
→ Edge Device nhận is_classifying
→ Bật/Tắt inference loop
